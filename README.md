# Homestead

Homestead is a household food system for planning, growing, cooking, preserving, storing, and tracking real food.

This repository contains the Homestead V1 product specification and application source.

## Product areas

- Household dashboard
- Family members and participation tracking
- Pantry inventory
- Recipes and meal planning
- Garden monitoring
- Preservation tracking
- Shopping lists
- Grow-light schedules
- Storage locations
